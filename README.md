# Fitv MCP

An MCP server for **[Fitv / freeimagetovideo.ai](https://freeimagetovideo.ai)** — Free image to video AI with no daily cap: your first clip needs no sign-up, then a free account keeps going. Every video comes with sound and no watermark.

## Links

- Site: [https://freeimagetovideo.ai](https://freeimagetovideo.ai)
- Pricing: [https://freeimagetovideo.ai/pricing](https://freeimagetovideo.ai/pricing)

## Install

```bash
npx fitv-mcp
```

## Develop

```bash
npm install
npm run build
npm start
```
